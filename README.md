### I personally use [Yarn](https://yarnpkg.com/) for nodejs package manager

### Requirement -

- Node.js == 18
- brain

# How to use

## Get & Install packages

```sh
git clone https://github.com/RinmeSTD/Yamakaze.git
yarn install
```

## How to start

```sh
yarn run build
yanr start
```

or

```sh
yarn run build
yanr run dev
```
